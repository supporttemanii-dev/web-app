Metode · konsistensi internal skala SWELTER

Suara responden · hal lain tentang panas ekstrem atau survei ini (Z4)

Catatan metode

Data dibaca langsung dari sheet Responses melalui endpoint Apps Script berkunci dan diolah di peramban; dashboard tidak menyimpan data apa pun. Data kontak dan klaim insentif berada di sheet terpisah dan tidak pernah dikirim. Seluruh uji dan model diestimasi ulang setiap kali data atau filter berubah: uji t Welch, Mann-Whitney, ANOVA, Kruskal-Wallis, χ² dan Fisher, korelasi Pearson/Spearman, regresi linear (OLS, HC1) dan logistik (Newton-Raphson), analisis faktor (komponen utama, varimax, analisis paralel), α Cronbach, logit bersyarat dengan opt-out (galat baku klaster per responden), simulasi Krinsky–Robb, dan mixed logit (simulasi Halton, BFGS, di Web Worker). Hasil dengan n kecil bersifat sementara.
