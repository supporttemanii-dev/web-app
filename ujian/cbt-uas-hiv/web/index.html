Memuat jadwal…
  • Gunakan laptop/PC dengan peramban Google Chrome atau Microsoft Edge terbaru.
  • Ujian berjalan dalam mode layar penuh. Pindah tab, membuka aplikasi lain, atau keluar dari layar penuh akan tercatat sebagai pelanggaran.
  • Jawaban tersimpan otomatis. Bila koneksi terputus, lanjutkan saja — data akan dikirim ulang.

  1. Ujian dikerjakan dalam mode layar penuh. Jangan menekan Esc, Alt+Tab, Windows, atau membuka tab/aplikasi lain.
